# Email Spam Classification (Machine Learning)

## 📌 Overview
This project builds a machine learning model to classify SMS messages as **Spam or Ham** using Python and Scikit-learn.

## 🚀 Technologies
- Python
- Pandas, NumPy
- Scikit-learn
- TF-IDF (Text Vectorization)

## 🧠 ML Workflow
1. Data cleaning & preprocessing
2. Text vectorization using TF-IDF
3. Train/test split
4. Model training (Naive Bayes, Logistic Regression)
5. Model evaluation

## 📊 Result
Accuracy: ~95%

## 📊 Model Performance
Accuracy: **96.7%**

Confusion Matrix:
- Precision (Spam): 1.00
- Recall (Spam): 0.76
